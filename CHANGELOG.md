# Changelog

## 0.1.0 — 2026-09-25

- First Windows x64 release of the QQmusicX GUI.
- Recursive scan with preserved subdirectories and original audio basenames.
- SQLite incremental state, output validation, LRC byte-copy, and safe skip behavior.
- Local invocation of `qmdec` and `ffprobe`; subprocess console windows are hidden on Windows.
- Portable ZIP and per-user installer distributions.
